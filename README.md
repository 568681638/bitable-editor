# bitable-editor

飞书多维表格插件：在表格右侧面板中逐条查看和编辑记录字段，支持视频 / 图片 / 音频预览，并内置服务端代理，解决浏览器访问不到的内网资源。

- 仓库：https://github.com/568681638/bitable-annotator
- 本地开发地址（飞书自定义插件）：`http://localhost:5173/`
- 内网部署地址：`https://dsw-vrip9i7k-8082-ado-euc.k8s.zytintra.com/proxy/6868/`

## 开发与部署

```bash
npm install
npm run dev          # Vite 开发服务器 → http://localhost:5173/
npm run build        # tsc + vite build → release/dist/
bash release/deploy/deploy.sh   # （在服务器上）安装 supervisor 配置并（重）启动 release/server/server.mjs，端口 6868
```

更新插件的流程：本机 `npm run build`（产物生成到 `release/dist/`）→ 把整个 `release/` 目录拷到服务器 → 服务器上 `bash release/deploy/deploy.sh`。
（也可以在服务器上 `git pull` 后构建，服务器不需要 `node_modules` 也能运行，只有构建时才需要。）
部署、日志、排障等细节见 [release/README.md](release/README.md)。

> `npm run deploy`（gh-pages，发布 `release/dist/`）只能发布纯静态页面，没有 `/api-proxy/`，不适用于需要代理的场景。

## 核心功能

1. **记录导航**：上一条 / 下一条；输入编号回车跳转。切换记录时调用 `showFieldValueEditor` 在表格中定位高亮。
2. **字段渲染**：文本、数字、单选、多选、日期、复选框、URL、公式、附件、人员、群组、位置、自动编号、电话、邮箱。
   - URL 字段自动识别类型，渲染为 `<video>` / `<img>` / `<audio>` / `<iframe>`（网页 16:9 自适应）。
   - 人员、群组只读展示名称。
   - 飞书「文本」类型字段一律用多行输入框：**值很短（没有换行、也没有折行）时高度与单行输入框完全一致**（外观也一样：无滚动条、无拖拽角），
     值里有换行、输入了回车，或者某一行超出宽度自动换行了，就对应增高（**长行自动换行，不出横向滚动条**，连续的长串如链接、哈希没有空格也会在边缘折断；最小一行，上限是窗口高度的 50%，面板页的侧边栏有缩放，会换算成屏幕像素；超出后内部滚动；
     手动拖拽右下角调整过高度后不再自动撑开）。飞书文本末尾自带的换行会被去掉，否则单行文本会多出一个空行。
     其他类型（电话、邮箱等）没有换行时仍用单行输入框。各类控件统一继承页面字体，保证同一栏里字体一致。
   - 多行输入框里 **Ctrl+A 分两步**（类似飞书文档）：第一次只选中光标所在的那一行，该行已整行选中时再按一次才全选；
     单行文本、空行、选区已跨行时直接全选。实现在 `src/shared/textarea.ts`。
3. **编辑与保存**：改动后保存按钮亮起，`setRecord` 写回表格；撤销按钮恢复原值。
   只读字段：首字段、URL、公式、关联、附件、人员、群组、位置、自动编号。
4. **☰ 更多功能菜单**（顶部栏最左边，侧边栏和面板页都有；第一次使用时图标上有小红点，打开过就消失）：第一项「使用教程」在新标签页打开教程（链接以服务端 `release/server/config.json` 的 `helpUrl` 为准，改完保存即生效、无需重新构建或重启；取不到配置时用 `src/shared/common.ts` 里的默认值 `HELP_URL`。双栏面板预览窗格空状态里的教程链接也用它）；面板页里还有「双栏布局」，展开后是「布局导入 / 布局导出」。后续新增的功能入口都放进这个菜单。
5. **刷新按钮 ↻**：同步字段元数据、视图可见字段顺序、单/多选选项、记录列表。

## 双栏面板

侧边栏标题栏的 **⧉** 按钮会在新标签页打开 `panel.html`：左边是「预览窗格」，右边是与多维表格侧边栏一致的「侧边栏」（编辑），中间是「分隔条」。

- **预览窗格展示哪个字段由用户决定**：把侧边栏里的字段名（标签）拖到预览窗格即可新增一个字段块；预览窗格没有顶栏，空白时才显示操作提示。
  字段块标题栏是「字段名 | 只读输入框（字段值，可选中复制）| ↗ 新窗口打开 | ✕ 关闭」；URL 字段在标题栏下方按类型渲染网页 iframe / 图片 / 视频 / 音频。
  其他字段的值只显示在标题栏里：值**没有换行且单行装得下**用单行输入框；**单行装不下**（或**有换行**）换成多行输入框，规则与侧边栏一致
  （长行自动换行、不出横向滚动条；高度随内容撑开；Ctrl+A 先选当前行再全选），区别只是上限更紧：窗口高度的 30%（标题栏撑得越高，下面的渲染区越小），超出后内部滚动。拖分隔条 / 改窗口大小导致宽度变化时，会重新判断：变窄了装不下就换成多行框，变宽了又装得下就换回单行框。**URL 字段**（内容渲染在下面的渲染区）的标题栏值例外：始终保持单行（过长用省略号，悬停看全文），免得把地址撑成很多行、挤占渲染区。
  不需要渲染的块，下方还有别的块时只占标题栏高度，下方没有东西时占满可用高度（全由这类块组成的一行，下方有别的块时整行也只占标题栏高度）。
  只有**字段名**可以拖动（用来移动字段块）；输入框不在可拖动区域内，所以能正常用鼠标选中文字。
- **字段块可上下左右任意切分**：把字段拖到某个字段块的上 / 下 / 左 / 右边缘（会高亮将占据的那一半），就从该方向切出新块，可嵌套（树形布局）。
  拖字段块标题可移动位置，拖分隔线调整大小，✕ 移除；同一字段只能放一块。
  拖到字段块之间或字段块旁边的空白处时，会找到对应的字段块并在该方向切分（空白区会高亮）。
- **已拖到预览窗格的字段，侧边栏不再显示**（不重渲染，其他字段里未保存的输入不受影响）；关闭预览窗格里的字段块后自动回到侧边栏，原有的预览渲染区也一并恢复。
  注意：预览窗格里的字段块是只读展示，拖走可编辑字段后需先关闭字段块才能在侧边栏编辑。
- **框选**：点侧边栏标题栏的 **⬚**（☰ 和 ↻ 中间）进入框选模式，然后在预览窗格里按住鼠标拖出矩形（网页、图片上也可以起手），碰到的字段块都会被选中，松开后自动退出框选模式；再点一次 ⬚ 或按 Esc 也会退出。布局是树形切分，选区会自动补成矩形：找到被碰到的字段块共同所在的那一层切分，把其中第一个到最后一个被碰到的之间全部选上。框出一个或多个字段块，松开后都直接圈成组合块（单个字段块也可以成组，组里只剩一个字段块时组合也保留，要散开点「取消组合」）；只框到已有的单个组合块时，只画一个虚线选框（不再有顶部操作条，免得盖住它们自己的标题）：要移动就拖组合框顶部的「⠿ 组合」，取消选择按 Esc、点别处或再点一次 ⬚。
- **组合块**：框选后自动组合，选中的块被圈进一个组合框（任意排布都可以）。拖组合框顶部的「⠿ 组合」移动整组；把字段或字段块拖到组合框的边缘（距边框约 12px 以内，或组合框顶部的操作条上），按整组来切分；拖到组里的块上，则在组内切分。「取消组合」恢复成普通字段块。
  **同步播放**：组合框上的另一个开关。打开后，组内各渲染区里的视频 / 音频一起播放、一起暂停、一起跳转进度：播放、暂停或拖动其中任何一个，其他的跟着一起（网页等无法控制的渲染内容不受影响）。各个音视频长度不一定一样，按秒对齐：同步到某个时间点，比它短的就停在自己的结尾，不会倒回去重播；长的继续播，短的播完后保持停着；长的把进度拖回短的范围内，短的立刻跟上并继续播；都停下后再点播放，所有人一起从当前位置重新开始（播完的从头开始）。只在播放、暂停、拖动进度这几个时刻对齐，播放过程中不持续校正，长时间播放可能有细微的先后差。开关本身不会让渲染区重新加载。
  **任一渲染**：组合框上的开关。打开后组内各字段只留标题栏，共用组底部的一个渲染区：按组内顺序找第一个能加载的链接显示（图片 / 视频 / 音频直连和服务端中转都失败就跳过，网页先问服务端 `/api/frame-check` 能否嵌入，禁止的跳过），正在显示的字段标题前有绿点；组内都没有能加载的内容时只剩标题栏。换记录、点 ↻ 刷新都会重新判断。组合和任一渲染都存进布局，导出 / 导入时一并带上。
- **全屏**：需要渲染的块（网页 / 视频 / 图片）左上角有悬浮的「全屏」按钮，点击后铺满整个浏览器窗口（盖住侧边栏），按钮变成「退出全屏」；点击或按 Esc 恢复。
  全屏只改样式（`position: fixed`）、不挪动 DOM，所以网页不会重新加载、视频不会重播；同一时间只有一个块能全屏。
- **侧边栏可完全收起**：点预览窗格与侧边栏之间分隔条中间的小按钮（▶）收起整个侧边栏，预览窗格占满页面；收起后分隔条留在右边缘，按钮变成 ◀，点一下展开。收起状态记在 localStorage，下次打开保持。
- **标题行可拖进预览窗格**：把侧边栏标题栏里的标题名「bitable-editor」（悬浮时是抓手光标）像字段名一样拖到预览窗格，就放进一份标题行（可切分、移动、进组合块、随布局导出 / 导入）。拖的是副本，侧边栏上的标题行原样保留；副本里的上一条 / 跳转 / 下一条、☰ 菜单、⬚ 框选、↻ 刷新都能用（操作转给侧边栏上的原按钮，状态同步），所以侧边栏收起后照样能翻记录、框选。块里的 ✕ 只移除这个副本。
- **布局导入 / 导出**（☰ 菜单 →「双栏布局」）：把当前数据表预览窗格的字段块布局存成 JSON 文件，方便分享、跨表格复用。
  导入时先按字段 ID 和名字对应当前表格的字段，ID 对不上再按字段名找（名字唯一才算）；**对应不上的字段块不会被丢掉**，保留原来的位置和大小，显示为虚线框的「待绑定」字段块（标题是原字段名）。
  把侧边栏里的字段拖到待绑定字段块上，是**替换**该字段块的字段（位置、大小不变），不是切分；拖到其他字段块或空白处仍按上下左右切分。字段后来被移出视图的字段块同样可以这样替换。
- 面板页侧边栏默认实际缩放为 0.85 × 1.05（更接近多维表格侧边栏的字号），界面上显示为 100%；侧边栏底部（撤销 / 保存左侧）的 A− / A＋ 以它为基准调整（60%～120%）。
- 预览窗格与侧边栏之间的分隔条可拖动调整宽度。布局（字段块树、大小、侧边栏宽度和缩放）存在浏览器 localStorage，换记录不丢；**预览窗格的字段块布局按数据表分别保存**，多维表格切到另一张表时，预览窗格自动换成那张表自己的布局，切回来还在。
- 数据来源：飞书 SDK 只能在多维表格内嵌的插件 iframe 里运行，所以面板页不直接访问表格——侧边栏插件需保持打开，
  它通过 `window.open` 句柄 + `postMessage`（校验同源）把当前记录推给面板页，面板页的翻页 / 刷新 / 保存也回传给插件执行。
  面板已打开且连着时，再点 ⧉ 只把它切回前台、不重新加载（保留网页滚动位置和视频进度）；面板没开或侧边栏刚刷新丢了连接时才重新打开，此时同名窗口会被复用并重新加载，所以连接以「每次页面加载的随机会话 ID」而不是窗口对象来区分新旧页面。面板页每 3 秒发一次心跳，侧边栏刷新后会自动重连；超过 12 秒无响应显示断开提示。
- 禁止嵌入的站点（`FRAMEBUSTER_DOMAINS`）只显示链接；
  其他因 X-Frame-Options / CSP 拒绝嵌入的站点 iframe 会空白（浏览器不提供检测），可点字段块标题上的 ↗ 新窗口打开。

## 批处理

侧边栏底部的切换条（「人工编辑 | 批处理」）切到「批处理」后，编辑区换成批处理面板：**按条件筛选记录 → 取输入字段调用服务端函数 → 把输出参数的结果写回字段（可选，不写就是只调用）**。实现在 `src/shared/auto-flush.ts`；函数由服务端 `release/server/functions/` 提供，写法见 [functions/README.md](release/server/functions/README.md)。批处理面板只在多维表格侧边栏里有；双栏面板右侧的侧边栏切到「批处理」只会提示回多维表格侧边栏使用。

- **筛选**：条件和条件组可嵌套，每组可选「满足全部（且）/ 满足任一（或）」并可取反。运算符：等于、不等于、包含、不包含、包含于、不包含于、开头是、结尾是、匹配正则、大于（等于）、小于（等于）、为空、不为空。
  「包含于 / 不包含于」的值按拆分符（英文逗号、换行或自定义）拆成列表；多选字段按选项逐个判断。大小比较两边都是数字时按数值，否则按文本。还没选字段的条件不参与筛选。
  筛选块右上角有「筛选」「统计」「预览」和 ☰ 菜单（导出 CSV、筛选条件导入、筛选条件导出；筛选条件可成文件复用）；面板标题旁显示最近一次筛选的命中数，条件改过后会提示需要重新筛选。
  「统计」读取记录并筛选后，在侧边栏里弹出悬浮窗查看（窗口里「在新标签页打开」可以用整个浏览器窗口看；新标签页预览页顶部也有「数据 | 统计」切换，两处是同一份统计代码 `src/shared/stats-view.ts`）：顶部下拉框选「统计类型」，默认「取值分布」——选一列，看命中记录在这一列上的取值分布（条形图，前 10 / 20 / 50 / 100 个或全部，其余合并成「其他」，空值单独一行；多选字段自动按选项拆开统计；日期列自动格式化并按时间排序）；「数值区间」——选一个数值列，分 5 / 10 / 20 段看直方图，摘要里有最小、最大、平均、中位数、合计；「日期趋势」——选一个日期列，按天 / 按月看记录数的变化，中间没有记录的日子补 0。图上方一行摘要。新增统计类型：在 `stats-view.ts` 的 `TYPES` 里加一项并补 `draw()` 里的分支。统计用点击那一刻的快照计算，不会自动更新。
  「预览」在悬浮窗口里看命中的记录（最多渲染 200 行，也可在新标签页打开完整预览：表头固定、列宽可调、点表头排序、虚拟滚动），「导出 CSV」导出全部命中记录的可见字段，都不写表。
- **输入**：不再是单独的一块，而是每个函数卡片里的「输入」部分，每一行是「入参下拉 ← 字段下拉」，每个函数各管各的映射，同名参数在不同函数里可以映射到不同字段。字段值先转成文本再传给函数。当前选的输出参数需要的入参（`requires`，纯调用则是全部入参）会自动补成输入行并标「必需」（不能删，只差字段要选）；其余入参可以点卡片右上角的「＋输入」手动添加（默认选第一个还没用的入参，可再改）、行末 × 删除。新加一个函数时，必需的入参里和别的函数同名且已配好的，会自动沿用同一个字段（之后可单独改）。多个函数用到同一个字段时，每条记录的这个字段只读取、转换一次。旧版全局的输入配置在第一次加载函数列表时自动拆给各函数。
- **函数**：选要调用的函数，并可选地把函数的出参映射到表格字段（参数 → 字段）。输出按函数分组：每个函数一张小卡片，卡片头部是函数名（悬停显示它所在的目录路径）、「＋输入」「＋输出」和移除整个函数的 ×，卡片里是它的输出参数行（输出参数下拉 → 字段下拉，输出参数可原地换成同函数的另一个，字段可选）。块底部的「＋函数」打开层级选择器（在选择器里勾选 / 取消输出参数时，面板里的卡片会变多变少，但选择器在屏幕上的位置保持不动，面板会自动滚动补偿），层级跟服务端 `functions/` 的目录结构一致（目录 → 函数 → 选项），所有目录和函数默认折叠，每个函数那一行的右侧有两个图标按钮：＋「添加」（把这个函数加进来，没有输出参数的分组就是只调用、不写字段；加上之后变成 －，点一下把它连同输出参数移除。真正调用函数是点「运行」的时候）和 ☐「全选」（一次加上全部输出参数，全加了就变成 ☑「取消全选」）；展开函数是各个输出参数的勾选列表（已添加的打勾，再点一下移除，可以连续勾选，不会收起），勾选输出参数会自动建出（或归入）对应函数的分组。删掉分组里最后一个输出参数，分组会留着变成纯调用。**输出字段都是可选的**：选了字段，就在拿到结果时顺带写入；不选，就只调用、不写入，运行后统计「已调用 N 条」。函数返回值要直接是目标字段类型的原生形态，面板不做宽松转换，类型不对只会让这一行失败；唯一的转换是单选 / 多选，函数给选项名，面板换成选项 ID（选项必须已存在）。
  支持写入的字段类型：文本、数字、货币、进度、评分、单选、多选、日期、复选框、电话、邮箱、超链接、人员；公式、附件、关联、地理位置等选了会在运行前被拦住。同一个字段不能被多个输出参数写入，同一个函数里同一个入参不能选两次。详细对应关系见 `release/README.md`。
- **运行**（底部右侧「运行」按钮；筛选块右上角的「筛选」按钮只统计命中数）：
  1. 读取当前视图的全部记录并按条件筛选，弹确认框显示命中条数、将被覆盖写入的字段，以及只调用不写入的函数，确认后开始；
  2. 分批调用：写回表格固定每 100 条提交一次（不足 100 也算一批）；调用函数时，前端按函数自己的 `batchSize`（默认 100，最大 5000）攒批或拆分——大于 100 的把几个 100 攒成一次调用，小于 100 的拆成几次（详见 functions/README.md）。同一个函数的多个输出一次调用拿齐，状态栏显示「进度 / 已写入 / 失败」；
  3. 运行中按钮变成「取消」，点了在当前这一轮处理完后停止，已写入的不回滚；
  4. 函数对某个出参返回 `null`，该字段保留原值；一行的所有输出都是 `null` 记为「跳过」，不写入。
- **异步函数**（定义里声明 `async: true` 的函数，适合一批要跑很久的）：点「运行」后只把数据**下发**给服务端，下发完就算完成（状态栏显示「已下发 N 条」），函数在服务端后台执行，结果存在服务端磁盘上；**只要这张表的插件页面开着**，面板会自动轮询、取回已完成的结果，用前端 SDK 按配好的字段映射写回（回写所需的记录 ID、字段随任务一起存，下发后刷新页面甚至关掉再开，都会接着写回）。异步是函数的一种运行模式：异步函数卡片的函数名右边有「异步」标记；下发后，「函数」块标题行的右上角（清空 × 旁边）出现一个「任务」标签，标签右上角有个状态点：**红色只表示失败**（只要有失败的行就变红；还有任务没结束时红点呼吸，表示“有失败、且还没跑完”），没有失败时 **橙色（呼吸）= 有任务在执行 / 等待写回，绿色 = 全部完成**，鼠标悬停显示数量。任务状态不占面板版面，所以不影响继续配置、运行别的函数。点标签弹出「任务记录」：标题栏有状态汇总、刷新和关闭；下面按「**批次 → 函数 → 任务**」分组——一次点「运行」是一个批次（标题是下发时间、总条数、整个批次的写回进度），批次里每个异步函数各占一段（带进度条），函数被自己的 `batchSize` 拆成的每个任务一张小卡片，写成“任务 2/5 · 第 101–200 条”（第几个 / 共几个，对应本批次里的第几到第几条）加一句话状态（排队 / 运行中已多久 / 等待写回 / 已写回的结果和用时 / 失败原因，可取消）；已写回的任务折叠起来，回写时失败的行折叠在对应批次的函数名下（存在浏览器本地，可复制 / 导出 / 清空，只针对这一组）；默认显示最近 4 个批次，更早的可以展开。点弹层外面或按 Esc 也能收起。同步函数和异步函数可以在同一次运行里混用：同步的照常算完立刻写回，异步的只下发。不用异步函数时，服务端不存任何结果，面板也不会请求任务接口。细节和限制（服务重启会让在途任务失败、回写需要页面开着、多个页面同时开着只有一个会认领回写）见 [functions/README.md](release/server/functions/README.md) 的「异步函数」一节。
- **搜索**：批处理面板里选项多的选择都能搜索。**字段下拉**（筛选条件的字段、函数输入 / 输出的字段）选项多于 7 个时，点开是「搜索框 + 选项列表」的弹层（命中部分高亮，↑↓ 选择、Enter 确认、Esc 关闭，选项少的仍用原生下拉）；**函数选择器**（「＋函数」「＋输出」）顶部有搜索框，按目录 / 函数 / 输出参数名过滤，命中的目录和函数自动展开，目录或函数名命中时它下面的全部内容都保留；历史记录窗口本来就有搜索。
- **失败明细**：某一行算不出来或值类型不对，只让这一行失败，不影响其他行。结束后状态栏给出「已写入 / 失败 / 跳过」统计，下方「失败明细」可展开，列出序号、记录 ID 和原因，支持复制全部、仅复制记录 ID、导出 CSV（含当时送给函数的输入）。整批调用出错（如服务不可达）则中断，已写入的保留。
- **历史记录**（批处理模式下侧边栏标题行最右边的历史记录图标按钮，类比浏览历史，但保存的是整个批处理面板的配置）：每次筛选、预览、统计、导出 CSV、运行都会记一条（连续两次同配置同操作只留最新一条，运行每次单独记，并带上结束时的统计），连同当时的筛选 + 函数（含各函数的输入）整套配置，按数据表各存最近 50 条。窗口里按天分组、可搜索，每条可「恢复全部」「仅恢复筛选」或用右上角 × 删除，每条记录可命名：点类型标签后面的「＋ 命名」（已命名的点名称改名，清空即取消），回车 / 点别处保存，搜索框也能按名称搜；命名过的记录超出 50 条上限时优先保留，名称随导出 / 导入带走；每条记录左上角的空心圆可勾选，搜索框下面一行是全选圆圈和「导入」「导出」「删除」：导出 / 删除只处理勾选的记录（没勾选时置灰），想清空就全选再删除；导出为 JSON 文件（字段带字段名，换一张表时按字段名重新对应，找不到的清空），导入时和现有的合并。每条记录右上角 × 删除单条，左下角「恢复全部」「仅恢复筛选」后面的「导出」只导出这一条；当前配置从没跑过时，恢复前会先确认，避免覆盖未保存的修改。
- 筛选、函数（含各函数的输入映射）的配置按数据表分别存在浏览器 localStorage 里；切到批处理时会重新读取函数列表（热加载的新函数立即可选），也可点面板里的重试。

## 服务端代理 `/api-proxy/`

浏览器（飞书页面）直接访问不了内网资源时，由本服务代为请求。

- 用法：`/api-proxy/<encodeURIComponent(目标URL)>`（相对路径，避免与 k8s 的 `/proxy/<port>/` 路由冲突）。
- 前端策略：内网 OSS 域名（`oss-cn-shenzhen-internal.aliyuncs.com`）一开始就走代理；其他 URL 先直连，
  `<img>` / `<video>` / `<audio>` / `<source>` 加载失败时，由全局 error 监听自动改走代理重试一次（`src/shared/common.ts` 的 `installProxyFallback`）。
- 服务端：支持 Range（拖进度条）、跟随重定向（最多 5 次）、流式转发；仅允许 GET / HEAD，不转发 cookie，且仅支持 http / https。
- 安全：**不设域名白名单**，有意放行内网网段（10/8、172.16/12、192.168/16、100.64/10），
  因此能访问本服务的人可以借它探测内网。已拦截回环（含 `localhost`）、链路本地 / 云元数据（169.254.x）、
  组播与保留地址，并固定 DNS 解析结果以防 rebinding。
- 不覆盖 `<iframe>` 网页：代理后页面里的相对链接和脚本会失效。

## 技术决策记录

> **服务端（`server/server.mjs`）必须兼容 Node 14**：DSW 容器自带的 Node 是 14.x，不支持 `??=` / `||=` / `&&=`（Node 15+）、`replaceAll`（Node 15+）、`Array.prototype.at`（Node 16.6+）等较新的语法和 API。
> 本机用新版 Node 测试通过不代表能在 DSW 上运行，改服务端后请避免使用这些特性。前端代码由 Vite 编译，不受此限制。

| 决策 | 原因 |
|------|------|
| 不用 SDK 表格事件自动刷新 | `RecordModify` 等事件触发太频繁，影响编辑体验；改为手动刷新按钮 |
| 切换记录时自动定位高亮 | 用 `showFieldValueEditor` 打开首字段编辑框，触发表格定位 |
| 不做 `normalizeOssUrl` | 内网 OSS 地址没有对应公网地址，转公网会 404 |
| 代理路径用相对路径 `api-proxy/` | 避免与 k8s 的 `/proxy/<port>/` 路由冲突 |
| 代理从“内网 OSS 白名单”改为“通用代理 + 失败自动回退” | 别的内网域名（如 bcebos，解析到 10.x）浏览器同样访问不到；见上方安全说明 |
| TTE 等会破框的域名不渲染 iframe | 只展示可点击链接，避免页面无限重刷 |
| 面板页用 window.open + postMessage，不用 BroadcastChannel | 插件在飞书页面里是第三方 iframe，Chrome 对其 BroadcastChannel / 存储做了分区，与顶层标签页同源也互通不了 |
| 静态文件开 br / gzip 压缩，带哈希的 `assets/*` 永久缓存，html 走 ETag | 插件经内网 k8s 代理访问，`main.js` 有 838KB（gzip 后约 265KB、br 约 237KB）；二次打开基本不用再下载 |
| 编辑区数据指纹没变就不重建 DOM | 保存后同步回来的相同数据不再重画，视频 / iframe 预览不会被重载、未保存的输入不会被清掉 |
| 记录按需分批加载（先取 ID 列表，内容每 40 条一块） | `getRecords` 每页最多 200 条，原先只取了第一页，视图超过 200 条时总数和翻页都不对；改为只取 ID 拿总数，内容按块加载并缓存，跳转到任意位置只等一次请求，连续翻页时在距块边缘 10 条内后台预取相邻块；刷新会清空缓存并只重载当前块 |
| 预览窗格里的网页 / 视频 / 图片放在固定图层里，按字段块内容区的位置叠加 | 布局变化（新增、移动、切字段块）会重建字段块的容器，iframe 一旦换了父节点就会被浏览器重新加载；渲染内容从不移动，布局变化时只更新位置和大小（`ResizeObserver` 监听占位内容区），网页的滚动位置、视频的播放进度都不会丢 |
| 异步函数的结果由前端 SDK 写回，服务端只存任务和结果、不写表格 | 服务端写表需要飞书自建应用、权限和白名单；让服务端只保管“已算好的结果 + 回写信息”，插件开着时再取回，用现有的写入代码和类型转换写回，不用另建应用，也不会让无鉴权的 `/run` 多出写表的能力。代价是回写必须有人开着插件；认领 / 确认机制保证多个页面同时开着时不会重复写 |
| 批处理的分批 / 攒批适配放在前端，服务端只告诉面板函数的 `batchSize` | 函数要几行一次因函数而异（调模型要小、查本地表可以大），但写回表格固定每 100 条；由面板按 `batchSize` 攒批或拆分，服务端 `/run` 收到多少行就一次交给函数多少行，不用在服务端凑请求（浏览器会串行等待上一个请求，服务端没法等后面的行） |
| 统计视图的代码只写一份（`stats-view.ts`），新标签页里用 `toString()` 把函数源码嵌进页面 | 新标签页是一份自带脚本的静态 HTML，侧边栏悬浮窗和它要共用同一套统计逻辑；所以这个函数必须自包含，且不能用模板字符串 / `${` / 反斜杠 |
| 用 supervisord 托管进程 | 部署环境是 DSW 容器，没有 systemd，pm2 自启不可用 |

## SDK 关键 API

| API | 用途 |
|-----|------|
| `bitable.base.getTableById(id)` | 获取表对象 |
| `table.getFieldMetaList()` | 获取所有字段元数据 |
